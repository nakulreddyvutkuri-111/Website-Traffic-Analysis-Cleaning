# Website Traffic Analysis & Data Wrangling

## Project Overview
This project focuses on data immersion and data wrangling techniques using a website traffic dataset. The analysis was performed in Kaggle using Python libraries such as Pandas and Matplotlib.

The project includes:
- Data exploration
- Data cleaning
- Handling missing values
- Removing duplicates
- Data transformation
- Basic data visualization
- Exporting cleaned dataset

---

## Dataset Information
The dataset contains website traffic event details including:
- Event type
- Date
- Country
- City
- Artist
- Album
- Track
- ISRC code
- Link ID

---

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Kaggle Notebook

## Project Workflow

### 1. Data Loading
Loaded dataset using Pandas.

### 2. Data Exploration
- Viewed dataset structure
- Checked columns and data types
- Generated statistical summaries

### 3. Data Cleaning
- Handled missing values
- Removed duplicate rows
- Converted date columns

### 4. Data Visualization
Created visualizations for:
- Event counts
- Top countries
- Top artists

### 5. Data Export
Saved cleaned dataset as CSV file.
